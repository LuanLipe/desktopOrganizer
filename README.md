# Desktop Organizer

Desktop Organizer is a Python automation project that automatically organizes files into folders based on their file extensions.

## Features

- Automatically organizes files
- Creates folders automatically
- Separates files by category
- Supports:
  - Images (.png, .jpg)
  - PDF files (.pdf)
  - Text files (.txt)
  - Music files (.mp3)
  - Video files (.mp4)

## Technologies Used

- Python
- os
- shutil

## How It Works

The program:
1. Reads all files inside a folder
2. Identifies the file extension
3. Creates folders automatically if necessary
4. Moves each file to its correct category
